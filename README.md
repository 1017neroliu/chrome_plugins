# 译页 · Chrome 网页翻译

使用自定义的大语言模型接口，将当前网页中的英文原地翻译为简体中文。

## 安装

需要 Chrome 116 或更新版本。更新扩展后，在 `chrome://extensions/` 点击「重新加载」，再刷新待翻译的网页。已保存的模型设置可以继续使用。

1. 在 Chrome 中打开 `chrome://extensions/`。
2. 开启右上角的「开发者模式」，点击「加载已解压的扩展程序」。
3. 选择包含 `manifest.json` 的目录。需要时，可从 Chrome 的扩展程序菜单将「译页」固定到工具栏。

## 配置模型

打开「译页」弹窗，点击「设置」，填写以下字段并点击「保存设置」。首次使用某个接口主机时，Chrome 会请求访问权限。

| 字段 | 填写方式 |
| --- | --- |
| Base URL | 兼容 OpenAI Chat Completions 的 API 地址，例如 `https://api.openai.com/v1` 或 `https://api.deepseek.com/v1`。扩展会自动追加 `/chat/completions`，也支持填写完整的接口地址。 |
| API Key | 服务商提供的密钥，通过 `Authorization: Bearer` 发送。 |
| 模型名称 | 服务商提供的模型 ID，例如 OpenAI 的 `gpt-4o-mini` 或 DeepSeek 的 `deepseek-chat`。 |

「测试连接」会向表单中的接口发送一句固定的英文，并显示模型返回的译文。保存后，翻译才会使用这组设置。

## 翻译网页

- 在普通 HTTP 或 HTTPS 网页上点击「翻译当前页」。默认优先识别 `main` 或 `article` 正文区域，跳过导航、侧栏和页脚。勾选「翻译全部区域」再点击翻译，可补翻其余文字。快捷键也使用已保存的范围。译文按批次显示，关闭弹窗后翻译会继续。
- 勾选「同时显示英文原文」后，中文译文会单独显示在对应英文段落下方。页面翻译完成后也可以随时切换显示方式，已翻译的文字会立即更新。
- 按 `Alt+Shift+Y` 直接翻译当前网页。macOS 上默认按 `Control+Shift+Y`。点击弹窗底部的快捷键入口可在 `chrome://extensions/shortcuts` 中查看或修改绑定。
- 优先处理当前屏幕内的文字，每页最多同时发送 3 个翻译批次。支持 OpenAI 兼容流式响应的模型会在每条译文生成后立即显示。每批模型请求最长等待 120 秒。多条文本的批次遇到超时时，会拆成更小的批次重试。
- 点击「恢复原文」可恢复已替换的文字，并停止应用尚未返回的译文。
- 若页面加载出新内容，或某一批次失败，再点一次「翻译当前页」可继续处理剩余文本。
- 翻译范围为网页主文档中当前已经渲染的文本。代码块、可编辑区域、iframe 和 Shadow DOM 跳过。Chrome 内置页面和 Chrome 网上应用店受浏览器限制。

设置和密钥保存在浏览器本地的扩展存储，不随 Chrome 账号同步。点击翻译后，待翻译的网页文本会发送到指定的模型服务，调用可能产生费用。远程接口建议使用 HTTPS。
